## Overview / Descripción General

### English
Software Architect specializing in 100% Cloudflare-native, zero-trust architectures. I design high-performance B2B applications by leveraging an Edge-first stack: **Astro** for zero-overhead frontends, **Hono.js** for high-throughput API routing, and **Cloudflare’s native primitives** (D1, KV, R2, Durable Objects) for distributed persistence—eliminating legacy database overhead and third-party cloud dependencies. Complex compute workloads are offloaded to **Rust** via WebAssembly (Wasm) or Cloudflare Containers.

My practice integrates continuous **DevSecOps**, automated **E2E QA testing**, and self-driven research in **ISO 27001**, **Zero Trust Architecture**, and **OWASP Top 10** security hardening.
